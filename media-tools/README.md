# Media Tools

Aplikasi web berbasis browser untuk kompresi dan konversi media.

Fitur:
- Kompresor Gambar (JPG, PNG, JPEG, WebP)
- Konversi Gambar:
  - PNG ke JPG
  - PNG ke JPEG
  - PNG ke WebP
  - JPG ke JPEG
  - JPG ke WebP
- Kompresor Video (MP4) menggunakan FFmpeg WebAssembly (ffmpeg.wasm)

Semua pemrosesan dilakukan secara lokal di browser klien untuk menjaga privasi.
